# WebDavAggregation

将多个 WebDav 存储聚合为一个, 推荐配合 OpenList 使用.

### 聚合机制

- 读取: 合并显示所有存储的文件列表
- 写入: 根据配置存储空间比例自动上传到空间最充足的上游存储
- 删除: 自动在多个存储中删除对应文件

### 冲突处理

- 存储中的相同文件: 优先删除操作时间较旧的文件, 若无差异则删除存储 id 较大的文件
- 同时上传相同文件: 阻止较后上传的文件
- 相同目录: 允许存在相同空目录

### 添加存储

直接在配置文件中添加即可, 注意 id 保持唯一, 重启服务后生效.

启动后, 存储 id 首次出现时会自动扫描该存储所有文件并索引到数据库.

### 删除存储

先从配置中删除对应存储, 重启服务, 再将被删除存储中的文件移动到聚合存储中.

启动后, 会自动删除数据库中不存在的存储 id 对应的数据.

注意: 不应复用和替换已有 id, 因为存储统计信息和文件索引与 id 关联.

### 重建索引

删除数据库文件后启动服务即可重建索引.
